# POP-Hub

동아리 부원의 코드를 모으고, 원본과 수정본의 관계를 계보(트리)로 기록하는 코드 저장소입니다.

- 학교 Google 계정으로만 로그인합니다.
- 다른 부원의 프로젝트에서 **수정본**을 만들면 원본 아래에 이어지고, 원작자가 자동으로 표기됩니다.
- 버전 기록, 원본–수정본 비교, 반영 요청, 줄 단위 댓글, 브라우저 안 실행(Python·HTML)을 지원합니다.

## 구조
- `index.html`, `css/`, `js/`: 빌드 없이 그대로 배포하는 정적 웹앱
- `js/config.js`: Supabase 주소와 공개(anon) 키. 비워 두면 브라우저 안에서만 동작하는 데모 모드
- `supabase/schema.sql`: DB 테이블, 행 단위 보안(RLS), 권한을 검사하는 서버 함수
- `privacy.html`: 개인정보처리방침
- `tests/`: 서버 SQL 권한 테스트, 서버 모드 화면 테스트 페이지

## 실행
```
python -m http.server 5173
```
브라우저에서 http://localhost:5173 을 엽니다.

설정·배포 방법은 [SETUP.md](SETUP.md)를 보세요.
